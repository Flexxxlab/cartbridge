Features of the CartBridge Walmart cart API

CartBridge turns an ingredient list into a filled Walmart cart. It is built for apps with recipes, meal plans or shopping lists. Get started or contact us.

Ingredients in, Walmart cart link out

You send names, quantities and units. For each ingredient CartBridge searches Walmart, picks the first in-stock match, and builds the affil.walmart.com/cart/addToCart link. The response lists matched products with prices, the ingredients it could not match (with a reason) and an estimated total.

Sensible quantities

Count units (each, can, bag or none) add the rounded-up number of items. Weight and volume units (lb, oz, cup) add one package with a note. Duplicates merge into one line. You can override with cart_quantity or pin an exact product with item_id.

Flutter Walmart add to cart

The cart_bridge package on pub.dev gives you CartBridge.openCart, a full-screen cart view with an "Open in app" hand-off, and CartBridgeClient if you want your own review screen. It works on Android, iOS and macOS.

A REST API for everything else

Authenticate with Authorization: Bearer cb_... or X-API-Key. Endpoints: POST /v1/cart, GET /v1/me, GET /v1/stores. Interactive docs are at /docs. More stores are planned; tell us which.

Your Walmart key stays off the device

Walmart's Affiliate API needs each request signed with an RSA private key. You add yours once in the dashboard. It is verified against Walmart, stored encrypted and never shown again. Your app holds only a CartBridge key that can build carts, is rate limited and can be revoked at any time.
