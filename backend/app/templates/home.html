Flutter Walmart add to cart

Add a "Send to Walmart cart" button with the cart_bridge package: one call opens a ready-made cart screen and hands off to the Walmart app. See the Flutter setup.

Grocery cart link API

POST /v1/cart returns a cart_url that fills a Walmart cart with every matched item. Open it in a WebView, a browser or the Walmart app. See all features.

Your Walmart key stays safe

Walmart signs every request with an RSA private key that cannot live in a mobile app. CartBridge stores yours encrypted on the server and signs requests for you.

How it works

  1. Sign up and add your Walmart Affiliate API credentials in the dashboard.
  2. Create a CartBridge API key.
  3. Send ingredients with name, quantity and unit.
  4. Open the returned cart_url. The shopper signs in and checks out on Walmart.
